## 🌑 Phase 0: Scoping & Syllabus

### **Canonical Home**: [https://react.dev](https://react.dev)

### **The Syllabus**

#### **Level 1: The Core (Fundamentals)**
*   **JSX & Components**: Understanding the declarative UI paradigm.
*   **Props & State**: Managing data flow and component memory (`useState`).
*   **Events & Logic**: Handling user interaction.
*   **Conditional Rendering & Lists**: Dynamic UI generation.
*   **Basic Effects**: Synchronizing with external systems (`useEffect`).

#### **Level 2: The Idiom (Thinking in React)**
*   **Lifting State Up**: Designing efficient data hierarchies.
*   **Context API**: Managing "Global" state without prop drilling.
*   **Custom Hooks**: Logic extraction and reuse.
*   **The "Standard" Performance**: Understanding reconciliation and the Virtual DOM.
*   **React Compiler (v1.0)**: Understanding how auto-memoization replaces manual `useMemo` and `useCallback`.

#### **Level 3: The Depths (React 19 Primitives)**
*   **Actions & Form Improvements**: Passing functions to `<form action>`.
*   **Advanced Hooks**: `useActionState`, `useFormStatus`, `useOptimistic`.
*   **The `use` API**: Reading Promises and Context conditionally.
*   **React Server Components (RSC)**: Moving logic to the server; understanding the boundary.
*   **`useEffectEvent`**: Solving the dependency array nightmare.

#### **Level 4: The Architect (High-Performance & Scaling)**
*   **Background Rendering**: The `<Activity />` component for state-preserving background updates.
*   **SSR Strategies**: Streaming SSR and Partial Pre-rendering (PPR).
*   **Cancellation**: Using `cacheSignal` for RSC resource management.
*   **Testing & TDD**: Mastering React Testing Library (RTL) and Vitest.
*   **Profiling**: Using Chrome DevTools Performance Tracks.

## 🔍 Phase 3: The Pattern Audit

### **Modern Idiom vs. Anti-Pattern**

| Pattern | Credibility (CS) | Recommendation |
| :--- | :--- | :--- |
| **`forwardRef`** | **0.2 (Legacy)** | **Avoid.** React 19 allows passing `ref` as a standard prop. |
| **Manual `useMemo`** | **0.5 (Conditional)** | **Secondary.** Use the **React Compiler** (CS 1.0) first. |
| **Direct State Mutation** | **0.0 (Forbidden)** | **Never.** Always use `setState` or `dispatch`. |
| **`useEffect` for data fetching** | **0.4 (SO Common)** | **Avoid in RSC.** Use Server Components or the `use` API (CS 1.0). |
